## 🔍 Descripción

Esta carpeta conserva los notebooks, scripts y componentes de versiones anteriores del sistema DogRecSys. Sirve como repositorio histórico del proceso iterativo de desarrollo, permitiendo revisar experimentos pasados y recuperar posibles funciones.
